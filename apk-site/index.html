Install in three steps

  1. 01

    Download the file

    Tap Download for Android above. Keep the notification open until the %SIZE% file finishes saving.

  2. 02

    Allow this one install

    Open the file from your notification shade or Files app. Android will ask permission to install unknown apps — allow it for that app only, then tap Install.

  3. 03

    Sign in and go

    Open Study Hall from your home screen and sign in with the same account you use on the web. Your workspace appears as you left it.

Play Protect may show a warning for any app installed outside the Play Store. Study Hall is a verified, self-signed release — choose Install anyway to continue.

iPhone & iPad

  1. 01

    Open it in Safari

    iOS only installs from Safari — Chrome and Firefox on iPhone cannot add an app to the home screen. Open nexusos-sigma.vercel.app in Safari.

  2. 02

    Share → Add to Home Screen

    Tap the share button in the toolbar, scroll the list and choose Add to Home Screen, then tap Add.

  3. 03

    Launch it from the home screen

    The icon opens Study Hall fullscreen with no browser bars, and signing in brings back the same subjects, timetable and progress you have on Android and the web.

There is no .ipa file to download: iOS refuses to install an app Apple has not signed, so the App Store or TestFlight is the only route. The native iOS build is in preparation — the moment its TestFlight or App Store link goes live, the Download for iOS button opens it directly.

What you get

Your own workspace

Every account keeps its own subjects, timetable and progress. Nothing is shared, nothing is pre-filled.

Fullscreen, no browser

The app takes over the whole screen — no URL bar, no tabs, no accidental reloads mid-session.

Updates without reinstalling

The app always loads the current build of the site, so new features arrive on their own.

Made for phones

Every module is laid out for touch — one-handed navigation, thumb-sized targets, dark by default.

Questions

Is this safe to install?

Yes. The file is a signed release built from the open-source Study Hall project, and the checksum above matches it byte for byte. You can verify the download before installing it.

Why isn't it on the Play Store?

Study Hall is an open-source project published directly, so releases ship the moment they're built instead of waiting on a store review.

Do I need Chrome on my phone?

Yes — the app uses your installed browser engine to render the site. Chrome, or any browser that supports Android Custom Tabs, works.

Is there an iPhone version?

Yes — install it from Safari with Add to Home Screen, using the three steps above. A native iOS build for the App Store is in preparation; until it ships there is no .ipa to sideload, because iOS only installs apps Apple has signed.

Will my data be the same as on the web?

It's the same account and the same workspace. Sign in on the phone and everything you've added — subjects, tasks, habits, reports — is already there.

How do I update the app?

Most of the time you don't have to: the app loads the live site, so features arrive automatically. A new APK is only needed if the app shell itself changes — install it over the old version and your data stays.
